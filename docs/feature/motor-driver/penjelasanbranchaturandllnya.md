\- setiap perubahan kecil itu dicommit and push

\- jangan bikin branch dari branch

\- aturan branch = boleh ngebranch tapi harus di satu branch dlu jangan langsung branch baru di commit ke main





nama branch:

feat/nama (bikin fitur baru)

fix/nama (perbaikan)

chore/nama (repo dalem repo)





git checkout -b feat/motor-driver (untuk membuat branch baru)

git push --set-upstream origin feat/motor-driver (bikin branch baru di origin nya)

aturan:
git add -A
git commit "comment"
git push
